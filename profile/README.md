# SSC-NG

Modernizing the Statistical Software Components (SSC) archive for Stata — a robust, community-governed, next-generation infrastructure.

## About

SSC-NG is building the organizational structure, technical infrastructure, and governance needed to modernize the SSC archive while preserving backward compatibility and continuity for current users.

## Goals

- Keep SSC open, durable, and community-governed
- Improve the archive's robustness, reliability, and long-term sustainability
- Modernize workflows and infrastructure without disrupting what already works
- Prepare SSC for the next decade of Stata package distribution
